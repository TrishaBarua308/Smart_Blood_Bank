# 🩸 Smart Blood Bank Management System

A lightweight, full-stack web application built with Python Flask, SQLite and HTML/CSS/ JavaScript.

## 🚀 Features
- **Become a Donor:** Register donor profile into SQL database with unique phone validation.
- **Find Donor:** Search donors dynamically based on Blood Group and Area.
- **My Profile:** View profile card using registered phone number.
- **Update Profile:** Edit and update name or area easily.

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
